# Audio Files

This directory contains sample audio files for footstep sounds.

## Adding Audio Files

To add your own audio files:

1. Place your `.mp3` or `.wav` files in this directory
2. The files will be automatically used by the sound agent
3. Common formats supported: MP3, WAV

## Sample Files (if you want to add them)

- `Footsteps on Gravel Path Outdoor.mp3`
- `UrbanFootstepsConcrete.mp3`

Note: Audio files are tracked with Git LFS. If you're pushing large audio files to the repository, make sure Git LFS is set up.
